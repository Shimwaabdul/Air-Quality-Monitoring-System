# Air Quality Monitoring System

## What It Does
An Arduino-based embedded system that uses air quality sensors 
to monitor and track pollution levels in real time, triggering 
alerts when air quality drops below safe thresholds.

## Problem It Solves
Poor air quality is an invisible health risk. This system 
provides automated, continuous monitoring without human 
intervention — relevant to schools, homes, and public 
spaces in urban environments like Kigali.

## Technologies Used
- Arduino IDE
- C++ (Arduino language)
- Air quality sensor (MQ series)
- LED/buzzer alert output

## How It Works
1. Sensor reads air quality data continuously
2. Arduino processes the readings
3. If levels exceed threshold → alert triggers automatically
4. Real-time feedback via output indicators

- Writing efficient C++ for microcontrollers
- Designing systems that operate autonomously without user input
